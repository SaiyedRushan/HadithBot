# Instagram DMs

Messages to send to MSA Instagram accounts, and the 64 accounts to send them to.
The handles come from [`msa-contacts.csv`](msa-contacts.csv). UTM is left out
because it already runs the bot.

## Which message to send

Use the first one for an MSA that hasn't heard from you. Use the second for the
32 that got the email on 20 Sep: that DM counts as their one follow-up, so after
it, leave them alone.

Instagram doesn't format anything, so paste these as plain text. Put the MSA's
name in the first line so it doesn't read as copied and pasted.

### 1. An MSA that hasn't heard from you

```
Assalamu alaikum! I'm Rushan, a York MSA alum. I made a free Discord bot called HadithBot. Every evening it posts one hadith, with a link to its source on Sunnah.com, and one of the 99 names of Allah with its meaning.

If [MSA NAME] has a Discord, it could be a nice thing to have in there. Someone with Manage Server adds it from hadithbot.app, then types /bismillah setup and picks a channel. It takes about a minute. It's free, there are no ads, and it can't read anyone's messages.

The York and UTM MSAs already use it. If you don't have a Discord, or it's not for you, no worries at all. Jazakum Allahu khayran!
```

For the five with a public Discord, change the start of the second paragraph
to: "I saw [MSA NAME] has a public Discord, so I thought it could fit in there."

### 2. An MSA that got the September email

```
Assalamu alaikum! I'm Rushan, a York MSA alum. In September I emailed [MSA NAME] about HadithBot, a free Discord bot I made that posts one hadith and one of Allah's 99 names into a channel every evening. Sending it here too in case the email got buried.

If you have a Discord and want it in there, everything is at hadithbot.app and setup takes about a minute. If not, no problem, I won't message about it again. Jazakum Allahu khayran!
```

### 3. MSA National

They don't run one server, so the ask is different: whether they'd mention it
to chapters.

```
Assalamu alaikum! I'm Rushan, a York MSA alum. I made a free Discord bot called HadithBot that posts one hadith and one of Allah's 99 names into a channel every evening. The York and UTM MSAs already use it.

Is there a newsletter or a resource list for chapters where something like this could be mentioned, for the MSAs that run a Discord? Everything is at hadithbot.app, and the code is public on GitHub. Jazakum Allahu khayran!
```

Send to [@msa.national](https://instagram.com/msa.national), or through
msanational.org/contact.

## Before you start sending

- **Send from your own account.** An exec will reply to a person they can look
  up. A bot's account reads as an ad.
- **10 to 15 a day, not all 64 at once.** DMs to people who don't follow you go
  to Message Requests, and Instagram limits how many of those you can send.
  Pasting the same text into dozens of requests in a row is how accounts get
  blocked from sending DMs for a few days.
- **Expect slow replies right now.** Late October is midterms. The five with a
  public Discord are worth doing this week; the rest might land better after
  exams.
