Where these ids are used

A channel starts at the very beginning unless you tell it otherwise. To begin somewhere specific, pass the ids from this page when you set the channel up:

start_book_id Which collection — the Book id column below.
start_chapter_id Which chapter inside that collection — the Chapter id column.
start_hadith_id Which hadith inside that chapter — a number from the Hadith ids column. Leave it out to start at the chapter's first.

So to start a channel at Sahih al-Bukhari's chapter on fasting: /bismillah setup start_book_id:1 start_chapter_id:30

Things worth knowing about the ids

  • Chapter ids belong to their book. Chapter 5 is a different chapter in each collection, so pass start_book_id whenever you pass start_chapter_id. Name a book on its own and the channel starts at that book's first chapter.
  • They aren't always consecutive, and don't always start at 1. Some collections number their chapters from 0, and a few (Sunan al-Nasa'i, Musnad Ahmad, Shama'il Muhammadiyah) have gaps. Copy the id from the table rather than counting rows.
  • Hadith numbers run across the whole book, not the chapter. The Hadith ids column shows where each chapter's numbering begins and ends, so a number from that range lands inside the chapter you picked.
  • These aren't sunnah.com reference numbers. They're this dataset's own numbering, which counts a little differently. Every hadith the bot posts carries a Sunnah.com button that searches out the same text there.
  • Nothing is lost by changing settings later. Rerun /bismillah setup without any start ids and the channel keeps its place; pass a new book or chapter and it moves there from that day on.

Looking the ids up from inside Discord

The same lists are available without leaving your server: /bismillah books prints the collections and their ids, and /bismillah chapters book:1 prints the chapters inside one of them. Both replies are ephemeral — only you see them. This page is the easier one to search, and it's the only place the hadith counts and number ranges are shown.
