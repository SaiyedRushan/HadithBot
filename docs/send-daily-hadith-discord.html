How to send a daily hadith to your Discord server

About a minute to set up. Free, and no account to create.

The short version

Add HadithBot to your server, then run /bismillah setup in the channel you want. It posts a hadith — and, if you like, Allah's names — every day at 6:00 PM Toronto time, picking up where it left off each time rather than repeating or posting at random.

☾ Add to Discord

Before you start: who can do this

Adding any bot to a Discord server needs the Manage Server permission. Server owners and admins have it. Moderators often don't — plenty of mod roles stop at Manage Messages, kick, ban and timeout, which isn't enough. If the server you want is greyed out on Discord's authorization screen, that's the reason, and you'll need an admin to add it for you.

Configuring the bot afterwards is a separate, lower bar: any member with Manage Channels can run setup.

Step 1 — Add the bot

Use the button above. You'll land on Discord's own authorization screen — no password is ever shared with the bot. Pick your server from the dropdown and press Authorize. HadithBot asks for only two permissions: View Channel and Send Messages.

Step 2 — Turn it on in a channel

Go to the channel you want the hadith in and run:

CommandWhat it does
/bismillah setup Starts daily messages in the current channel, with the defaults: three hadiths and three names a day.
/bismillah setup channel:#reminders Sets it up for a different channel without leaving the one you're in.
/bismillah setup hadiths_per_day:1 One hadith a day instead of three. Any number from 1 to 10.
/bismillah setup names_per_day:1 One of Allah's names a day. Both counts accept 1 to 10 — there's no way to switch either off entirely short of stopping the channel.

The reply is ephemeral — only you see it, so setup doesn't clutter the channel.

Starting from a particular hadith

By default a channel begins at the beginning. To start somewhere specific, pass a book, chapter, or hadith id: start_book_id, start_chapter_id, start_hadith_id. Use /bismillah books and /bismillah chapters to look the ids up inside Discord, or read the whole list — every collection, every chapter, and the hadith numbers each one spans — on the books & chapters page.

If you name a book or chapter but no hadith, it starts at that chapter's first hadith rather than keeping a stale number. And when a chapter runs out mid-batch, the next day continues into the following chapter or book — the daily count is always honoured.

Changing settings later won't lose your place

This is the question people ask most. Re-running /bismillah setup edits the existing configuration: anything you leave blank keeps its current value, including the reading position. So changing from three hadiths a day to one does not restart the collection.

Running it in more than one channel

Each channel is independent. It keeps its own per-day counts and its own place in both the hadiths and the names, so a study channel can take one hadith a day while a general channel takes five, and neither affects the other. Run /bismillah status to see every channel in your server that's set up, and where each one is.

When the messages arrive

Every day at 6:00 PM Toronto time (America/Toronto), in each channel you've set up. There's no per-server time zone setting today.

Pausing or stopping

/bismillah stop ends daily messages for a channel and deletes that channel's stored row — its position and settings included. It isn't a pause; running setup again starts fresh unless you pass a starting point.

If it isn't posting

  • Check the bot can see the channel. The most common cause is a private channel the bot's role has no access to. It needs View Channel and Send Messages in that specific channel, not just server-wide.
  • Check the channel is actually set up. Run /bismillah status — if the channel isn't listed, setup didn't complete.
  • Check you're not waiting on the wrong clock. 6:00 PM Toronto is early morning in much of Asia and late night in Australia.
  • A failure in one channel won't stop the others. Each channel is delivered independently, so a permissions problem in one place doesn't silence your whole server.

Pulling a hadith on demand

Separately from the daily post, anyone in the server can ask for one any time: /bismillah random for a random hadith, or /bismillah specific to look one up by book and chapter. For the names there's /bismillah random_name and /bismillah specific_name. None of these need special permissions.
