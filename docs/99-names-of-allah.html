The 99 Names of Allah

Arabic, transliteration and meaning — the same list HadithBot posts.

Have one sent to your Discord server each day

HadithBot posts Allah's names to any channel you choose, a few each day, together with the meaning and a short reflection on when to call upon that name in your dua. It picks up where it left off, so a server works through all 99 in order rather than seeing the same few. It's free, and setup is one command.

How HadithBot sends them

Run /bismillah setup in the channel you want. By default it posts three names a day alongside three hadiths, at 6:00 PM Toronto time. You can change how many with the names_per_day option (1–10), or start from a particular name with start_name.

Each name arrives with its Arabic, its meaning, and a line on when to call upon it — for example, to call upon Al-Ghafoor when the weight of your sins burdens you. You can also pull one on demand any time with /bismillah specific_name, or ask for a run of three with /bismillah specific_names.

Every channel keeps its own position, so different channels can be at different points in the list. Full setup instructions are on the main page.
