HadithBot name match: UI mockup

Static mockup to agree the screens and wording before building. Discord message first, then the game that opens inside Discord. The game keeps the look of MugUp's pair match (blue names, amber meanings, one shuffled grid of 20 cards). Example day: the channel was just sent name 58, so the match uses names 49 to 58.

1. The message HadithBot posts, last in the daily batch (nobody has played yet)

Posted right after today's name and hadith. This one message is the leaderboard: the bot edits it each time someone finishes.

4. The game opens inside Discord: start screen

The timer starts on the button, not on load, so a slow phone doesn't cost anyone time. The rules are on screen before the press.

Discord · #daily-hadith · HadithBot

Match each name of Allah to its meaning

Names 49 to 58, including today's name, Al-Mubdi. Everyone in this server gets the same 10.

Tap a name, then tap its meaning. You get a point for each name you match without a wrong guess. You have one try today. If two people get the same score, the faster time ranks higher.

5. Playing (computer or tablet)

MugUp's website layout: one shuffled grid, names in blue with the Arabic underneath, meanings in amber. A wrong pair flashes red for a second, then both cards unselect. "Next Set" and "Skip Set" are gone because there is only one set; "Exit" became a button that says what it does.
